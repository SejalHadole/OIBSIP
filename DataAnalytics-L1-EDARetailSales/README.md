# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project explores a retail sales dataset using Python to understand sales patterns, product category performance, and customer purchasing trends.

## Objectives
- Analyze total sales by product category.
- Examine monthly sales trends.
- Compare sales by gender.
- Count transactions across product categories.
- Analyze sales across different age groups.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
The dataset contains 1,000 transactions and 9 original columns, including Date, Gender, Age, Product Category, Quantity, Price per Unit, and Total Amount.

## Key Findings
- Electronics recorded the highest total sales among the three product categories.
- May had the highest monthly sales in the dataset.
- Female customers contributed slightly more total sales than male customers.
- Clothing had the highest number of transactions.
- The 51–60 age group contributed the highest sales among the defined age groups.

## Files
- `Retail_Sales_EDA.ipynb` — Jupyter notebook containing the analysis and visualizations.
- `retail_sales_dataset.csv` — Dataset used for the analysis.

## Conclusion
The analysis summarizes retail sales patterns across product categories, months, gender, and age groups using Python and data visualization.
